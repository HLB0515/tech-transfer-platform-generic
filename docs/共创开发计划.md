# 科技成果转化平台共创开发计划

## 共创目标

与领导共同推进一个可演示、可迭代、可接入真实模型的科技成果转化平台，重点呈现成果库、需求库、专家库、供需匹配、一对一对接室和多智能体协作。

## 推荐协作方式

建议采用“双平台协作”：

- GitHub：代码、版本、任务、缺陷、功能迭代。
- 飞书：产品讨论、会议纪要、方案文档、演示脚本、领导反馈。

## 角色分工建议

| 角色 | 建议职责 |
| --- | --- |
| 项目负责人 | 明确平台定位、业务场景、演示目标、优先级 |
| 产品共创人 | 审阅页面信息架构、业务流程、对接场景真实性 |
| 技术开发 | 前端页面、后端接口、数据库、智能体接入 |
| 内容与案例 | 整理真实成果、需求、专家、政策、资本机构样例 |
| 演示负责人 | 准备路演脚本、录屏、领导汇报材料 |

## 当前版本能力

- 门户首页
- 成果库、需求库、专家库
- 供需匹配
- 智能体广场
- 一对一对接室演示
- 本地数据持久化
- OpenAI API 接入预留

## 下一阶段优先级

1. 真实网站化
   - 横向门户导航
   - 首页运营动态
   - 成果/需求/专家详情页
   - 真实对接流程

2. 真实模型接入
   - 配置 `OPENAI_API_KEY`
   - 让成果转化官、需求解析师、专利猎手、政策顾问、技术尽调助手、投融资对接官调用真实模型
   - 保存问答记录

3. 真实数据建设
   - 增加成果、需求、专家、政策、基金样例
   - 统一字段标准
   - 支持筛选、搜索、详情弹窗

4. 演示路线
   - 企业发布需求
   - 平台推荐专家与成果
   - 一对一洽谈室逐句推进
   - 输出对接纪要、样件验证计划、政策/基金建议
