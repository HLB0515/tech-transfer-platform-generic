# 公网部署指南

本项目包含 Node.js 后端、JSON 数据库、管理员后台和大模型接口，推荐部署到 Render / Railway / Fly.io 等可运行后端服务的平台。GitHub Pages 只能托管静态页面，不适合作为完整演示入口。

## 推荐方式：Render

1. 打开 https://render.com/ 并登录。
2. 点击 `New +`，选择 `Blueprint`。
3. 连接 GitHub 仓库 `HLB0515/tech-transfer-platform`。
4. Render 会读取项目根目录的 `render.yaml`。
5. 在环境变量里填写：
   - `ZHIPU_API_KEY`：你的智谱 API Key
   - `ZHIPU_MODEL`：`glm-4-flash`
   - `ZHIPU_SEARCH_MODEL`：`glm-4-plus`
6. 点击 `Apply` 或 `Deploy`。
7. 部署完成后，Render 会生成公网网址，格式通常类似：
   `https://tech-transfer-platform.onrender.com`
