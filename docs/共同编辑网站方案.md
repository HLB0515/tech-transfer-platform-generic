# 共同编辑网站方案

## 先说明

`http://localhost:3000` 只能在你自己的电脑上打开。领导在另一台电脑上打不开，也不能直接一起编辑。

要实现“你和领导一起编辑、一起看网站”，建议用：

- GitHub：共同编辑代码
- GitHub Codespaces：云端打开项目并运行网站
- 云端预览地址：双方同时打开页面看效果

## 推荐方案：GitHub + Codespaces

### 你需要做

1. 新建一个 GitHub 私有仓库
2. 把本项目上传到仓库
3. 邀请领导为协作者
   - 邮箱：`LawSchool.Tsinghua@gmail.com`
4. 在 GitHub 页面点击 `Code -> Codespaces -> Create codespace`
5. 在 Codespaces 终端运行：

```bash
npm start
```

6. Codespaces 会提示打开端口 `3000`
7. 你把预览链接发给领导

### 领导能做

- 在线查看网站
- 在线编辑代码
- 提 Issue 提需求
- 在 Pull Request 里审核你的改动
- 和你一起修改页面文案、样式、流程

## 如果只想一起看，不一起改代码

可以先部署到 Render、Railway、Fly.io 或服务器，得到一个公开网址。

领导能打开网站，但不能直接改代码。

## 如果想临时分享你本机 localhost

可以用 Cloudflare Tunnel 或 ngrok，把你本机的 `localhost:3000` 映射成临时公网地址。

适合临时演示，不适合长期共同开发。

## 最推荐的共创流程

1. GitHub 私有仓库放代码
2. Codespaces 共同编辑
3. 飞书放产品文档和领导反馈
4. 每次完成一版，在 GitHub Pull Request 里留截图和说明

## 给领导发的邀请文案

```text

1. GitHub 用于代码共同编辑和版本管理；
2. Codespaces 可在线运行网站，不需要本地安装环境；
3. 飞书用于产品方案、会议纪要、页面反馈和演示材料。

```
