# 大模型与联网搜索配置

本项目已支持智谱 GLM 真模型和联网搜索。为了保护 API Key，密钥不要提交到 GitHub，请使用本地 `.env` 或部署平台环境变量。

## 本地运行

在项目根目录创建 `.env` 文件：

```bash
PORT=3000
HOST=127.0.0.1
ZHIPU_MODEL=glm-4-flash
ZHIPU_SEARCH_MODEL=glm-4-plus
ZHIPU_API_KEY=替换为你的智谱APIKey
```

然后启动：

```bash
node server.js
```

打开：

```text
http://127.0.0.1:3000
```

进入「智能体广场」后：

- 不勾选「联网搜索」：使用 `glm-4-flash`，适合普通业务问答。
- 勾选「联网搜索」：使用 `glm-4-plus` 的搜索工具，适合查询最新政策、新闻、申报动态。

## GitHub Codespaces

如果在 Codespaces 中协作：

1. 打开 GitHub 仓库。
2. 进入 `Settings`。
3. 找到 `Secrets and variables` / `Codespaces`。
4. 新增 secret：
   - Name: `ZHIPU_API_KEY`
   - Value: 你的智谱 API Key
5. 在 Codespace 终端运行：

```bash
npm start
```

## 部署上线

部署到 Render、Railway、Fly.io 等平台时，在平台后台添加环境变量：

```text
ZHIPU_MODEL=glm-4-flash
ZHIPU_SEARCH_MODEL=glm-4-plus
ZHIPU_API_KEY=替换为你的智谱APIKey
```

不要把真实 Key 写进 `server.js`、`.env.example`、README 或任何提交记录。
